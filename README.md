# 📰 Fake Headline Generator (Python)

A beginner-friendly Python project that generates **random and fun fake news headlines** based on user input.
This project is perfect for learning **lists, loops, random module, and string formatting** in Python.

---

## 🚀 Features

* Takes user input for the subject
* Randomly selects an action and an object/place
* Generates a unique headline every time
* Runs continuously until the user types `exit`

---

## 🧠 Concepts Used

* Python Lists
* While Loop
* User Input
* `random.choice()`
* String Formatting (f-strings)

---

## 📂 Project Structure

```
fake_headline_generator.py
```

---

## ▶️ How to Run

1. Make sure Python is installed
2. Clone this repository or copy the file
3. Run the script:

```bash
python fake_headline_generator.py
```
